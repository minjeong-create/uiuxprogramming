## 새로 추가한 기능
7주차 학습 설정 흐름에 학습 기록 목록을 추가하였다. 학습 완료 후 기록을 저장하고, 각 기록의 완료 상태를 변경할 수 있도록 하였다.

## 인터랙션 시나리오
행동: 학습 설정을 완료하고 기록을 등록한다.
조건: 학습 설정 정보가 입력되어 있는가?
성공 반응: 학습자 이름, 학습 시간, 질문 설정이 기록 목록에 표시된다.
취소: 완료 취소 버튼을 누르면 학습 상태가 '진행 전'으로 변경된다.
다음 행동: 새 학습을 완료하여 기록을 추가하거나 기존 기록의 상태를 변경한다.

## 테스트 기록
학습 완료 후 기록 추가 및 정보 표시: 정상 동작 확인
기록 번호 순서대로 표시: 정상 동작 확인
학습 완료 및 완료 취소에 따른 상태 변경: 정상 동작 확인
다시 시작 후 기존 기록 유지 및 새 기록 추가: 정상 동작 확인
모바일 화면에서 기록과 버튼 표시: 정상 동작 확인
