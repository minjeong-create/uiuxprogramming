## 4. 테스트 과업
### T1. 기존 학습 계획 이어서 작성하기
학습 계획을 작성하던 중 화면이 새로고침된 상황에서 이전에 작성하던 내용을 복구하여 계획을 완성한다.

### T2. 새로운 학습 계획 작성하기
기존에 작성하던 학습 계획 대신 새로운 계획을 만들려고 한다. 기존 임시 보관 내용은 버리고 새로운 계획을 작성하여 저장한다.

## 5. 테스트 진행 방법
참여자에게 과업의 목표와 상황만 안내하고 클릭 순서나 사용 방법은 알려주지 않는다. 참여자가 직접 서비스를 이용하도록 하며 행동, 발화, 소요 시간, 도움 여부 및 어려움을 관찰한다.

# D. 사후 설문 및 인터뷰 결과
## 1. 사후 설문
각 항목은 1점(매우 어려움)부터 5점(매우 쉬움)까지 평가함.

- **기존 임시 보관 내용을 복구하기 쉬웠는가?** 4점
- **각 단계의 안내 문구를 이해하기 쉬웠는가?** 4점
- **기존 초안을 삭제하고 새 계획을 작성하기 쉬웠는가?** 5점
- **저장 완료 여부를 확인하기 쉬웠는가?** 4점

## 2. 사후 인터뷰

### Q1. 사용하면서 가장 편리했던 기능은 무엇인가요?
기존에 작성하던 내용을 복구할 수 있는 임시 보관 기능이 편리했음.

### Q2. 사용하면서 불편하거나 헷갈렸던 부분은 무엇인가요?
임시 보관 안내 영역이 눈에 잘 띄지 않아 처음에는 확인하기 어려웠음.

### Q3. 개선되었으면 하는 부분이 있나요?
임시 보관 안내 영역의 색상을 변경하여 더 눈에 잘 띄도록 개선하면 좋겠음.

### Q4. 전체적인 사용 경험은 어땠나요?
기존 작성 내용을 잃지 않고 이어서 작성할 수 있어 편리했음.

## 3. 결과 요약
- 임시 보관 및 복구 기능은 작성 중이던 내용을 이어서 작성하는 데 도움이 됨.
- 기존 초안을 삭제하고 새로운 계획을 작성하는 과정도 비교적 쉽게 이해할 수 있었음.
- 임시 보관 안내 영역의 가시성을 개선할 필요가 있음.

# E. 개선 및 재검증
## 1. 1차 테스트에서 발견한 문제
- **관찰 내용:** 임시 보관 안내 영역이 눈에 잘 띄지 않음.
- **문제점:** 배경색과 글자색의 구분이 약해 안내 영역을 쉽게 인식하기 어려움.
- **개선 필요성:** 안내 영역의 시각적 가시성 개선이 필요함.

## 2. 개선 내용
1차 사용자 테스트에서 임시 보관 안내 영역의 가시성이 낮다는 피드백을 확인함.
이를 개선하기 위해 다음과 같이 수정함.

- 안내 영역의 배경색을 기존보다 진한 연두색 계열로 변경
- 테두리에 초록색 계열을 적용하여 영역 구분 강화
- 안내 문구의 글자색을 진한 초록색으로 변경
- 버튼 색상을 안내 영역과 어울리도록 조정

## 3. 개선 전후 비교
### 개선 전
- 배경색: 연한 배경색
- 테두리: 눈에 띄지 않는 테두리
- 안내 문구: 회색 계열 글자
- 전체 가시성: 안내 영역 구분이 약함

### 개선 후
- 배경색: 구분이 명확한 연두색
- 테두리: 초록색 계열 테두리
- 안내 문구: 진한 초록색 글자
- 전체 가시성: 안내 영역 구분 강화

## 4. 1차·2차 테스트 비교

### 안내 영역 가시성
- 1차 테스트: 안내 영역이 눈에 잘 띄지 않음.
- 2차 테스트: 안내 영역을 쉽게 인식함.

### 과업 수행
- 1차 테스트: 두 과제를 수행함.
- 2차 테스트: 두 과제를 원활하게 수행함.

### 도움 제공
- 1차 테스트: 도움 없이 수행함.
- 2차 테스트: 도움 없이 수행함.

### 전체적인 사용 경험
- 1차 테스트: 안내 영역 개선이 필요함.
- 2차 테스트: 개선된 가시성에 긍정적인 반응을 보임.

## 7. 반복 수행에 따른 영향
동일한 참여자가 같은 과업을 반복 수행하였기 때문에 서비스 이용 방법에 익숙해지는 학습 효과가 발생했을 가능성이 있음.
따라서 2차 테스트에서 나타난 긍정적인 변화가 디자인 개선뿐 아니라 반복 수행의 영향도 받을 수 있음을 고려함.

## 8. 기능 회귀 QA 결과

### 통과
- 2단계 새로고침 후 입력값 및 선택값 복구
- 3단계 새로고침 후 요약 내용 복구
- 저장 중 초기화 버튼 비활성화
- 최종 저장 성공 후 임시 보관 내용 삭제
- 안내 영역 색상 개선

### 미확인
- 저장 실패 상황
- 임시 보관 실패 상황

### 재검증 필요
- 안내 영역 가시성 개선

## 9. 최종 정리
1차 사용자 테스트에서 임시 보관 안내 영역의 가시성이 낮다는 문제를 발견함. 이를 개선하기 위해 배경색, 테두리 및 글자색을 변경하여 안내 영역이 더 명확하게 구분되도록 수정함.
이후 동일한 참여자에게 같은 과업을 다시 제시하여 개선된 안내 영역의 인식 여부와 과업 수행 과정의 변화를 확인하는 방식으로 재검증함.
이번 테스트를 통해 기능 자체의 정상 동작뿐 아니라 사용자가 기능을 쉽게 발견하고 이해할 수 있도록 시각적 가시성을 확보하는 것도 중요하다는 점을 확인함.
