## 새로 추가·수정한 기능
글자 대비, 이미지 설명, 현재 메뉴 표시, 본문 바로가기 및 키보드 초점 표시 등 웹 접근성 기능을 개선했습니다.

## 주요 개선 내용
현재 메뉴와 필터에 굵기 및 밑줄을 적용하고, 이미지 대체 텍스트와 명확한 입력 라벨을 제공합니다. 키보드 초점 표시와 모바일 메뉴 Esc 닫기 기능을 추가했습니다.

## 확인 순서
1. 글자와 배경의 색 대비, 이미지 설명 및 입력 라벨을 확인합니다.
2. Tab, Shift+Tab, Enter, Space 키로 메뉴와 버튼을 조작하고 초점 이동을 확인합니다.
3. 첫 Tab으로 본문 바로가기가 표시되는지, 모바일 메뉴가 Esc 키로 닫히는지 확인합니다.
4. 안내 및 오류 메시지가 이해하기 쉽게 표시되는지 확인합니다.
