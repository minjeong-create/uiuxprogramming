## 4주차 반응형 수정

## 확인할 문제
작은 화면에서 메뉴, 기능 카드, 이메일 폼이 좁아보였다

## 수정한 내용
- viewport 메타 태그를 추가하였다.
- 콘텐츠에 width 와 max-width를 함께 사용하였다.
- 기능 카드 목록을 반응형 Grid로 변경하였다.
- 768px 이하에서 메뉴, 카드, 폼을 한 열로 구성했다.

## 확인할 화면 너비
1100px, 769px, 768px, 390px



## 5주차 이메일 구독 기능 구현

## 확인할 문제
이메일을 입력하고 구독 신청을 할 수 있는 기능이 필요했다.

## 수정한 내용
- 이메일 입력값이 비어 있는지 확인하도록 하였다.
- 이메일을 입력하지 않으면 안내 메시지가 표시되도록 하였다.
- 이메일 입력 후 구독 신청 시 구독 완료 메시지가 표시되도록 하였다.
- 구독 완료 후 버튼이 구독 완료로 변경되도록 하였다.
- 구독이 완료되면 버튼을 다시 누를 수 없도록 비활성화하였다.
- submitCount를 사용하여 구독 신청 횟수를 저장하도록 하였다.

## 확인할 기능
이메일을 입력하지 않고 신청했을 때 안내 메시지 확인
이메일 입력 후 신청했을 때 구독 완료 메시지 확인
구독 완료 후 버튼 상태 확인

## 7주차
StudyMate - 공부 습관 관리

## 사용자의 목표
- 사용자: 규칙적인 공부 습관을 만들고 싶은 사람
- 목표: 공부 목표를 설정하고, 학습 시간과 기록을 확인하여 꾸준한 공부 습관을 만든다.

## 사용자의 흐름
- 서비스에 접속하여 공부할 목표를 설정한다.
- 공부할 내용을 정하고 학습을 시작한다.
- 공부한 시간을 기록하고 학습 내용을 정리한다.
- 학습 기록과 목표 달성 여부를 확인한다.
- 학습 결과를 바탕으로 부족한 부분을 개선하고 다음 목표를 설정한다.


## 인터랙션 시나리오
1. 시작 및 목표 설정 안내
행동, 이벤트: 공부 목표 입력란에 내용을 입력하고 '목표 설정 시작하기'를 클릭한다.
조건: 공부 목표가 입력되었는가?
반응, 다음 상태: 목표가 비어 있으면 다음 단계로 이동할 수 없다. 목표가 입력되면 공부 시간 설정 화면을 연다.

2. 목표 입력
행동, 이벤트: 공부할 목표를 입력하고 '학습 시간 설정하기'를 클릭한다.
조건: 앞뒤 공백을 지운 목표가 비어 있는가?
반응, 다음 상태: 비어 있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다. 값이 있으면 저장하고 학습 시간 설정으로 이동한다.

3. 학습 시간 설정
행동, 이벤트: 공부할 시간을 설정하고 '학습 시작하기'를 클릭한다.
조건: 학습 시간이 설정되었는가?
반응, 다음 상태: 시간을 설정했을 때만 공부를 시작할 수 있다.

4. 학습 기록 확인
행동, 이벤트: 목표와 공부 시간, 학습 기록을 확인하고 '수정하기' 또는 '학습 완료하기'를 클릭한다.
조건: 수정할 것인가, 완료할 것인가?
반응, 다음 상태: 수정하면 기존 설정을 유지하고 목표 설정으로 돌아간다. 완료하면 학습 결과 안내로 이동한다.

5. 완료와 다시 설정
행동, 이벤트: 학습 결과를 확인하고 필요하면 '다시 설정하기'를 클릭한다.
반응, 다음 상태: 다시 설정하면 새로운 목표와 학습 시간을 입력할 수 있도록 초기화하고 목표 입력부터 다시 시작한다. 기존 학습 기록은 유지한다.

## 확인할 문제
- 발표 훈련에 필요한 조건을 설정하고, 사용자가 입력한 내용에 따라 다음 단계로 이동할 수 있는 기능이 필요했다.

## 수정한 내용
- 서비스 이용 동의 후 안내창을 통해 훈련을 시작하도록 하였다.
- 학습자 이름을 입력하지 않으면 오류 메시지가 표시되도록 하였다.
- 학습 시간을 선택할 수 있도록 하였다.
- 질의응답 포함 여부에 따라 질문 수 선택 영역이 표시되거나 숨겨지도록 하였다.
- 이전 및 다음 버튼을 통해 단계별 화면을 이동하도록 하였다.
- 설정한 학습자 이름, 학습 시간, 질의응답 여부가 확인 화면에 표시되도록 하였다.
- 완료 버튼을 누르면 훈련 완료 화면으로 이동하도록 하였다.
- 다시 시작 버튼을 누르면 입력값과 선택 상태가 초기화되도록 하였다.

## 확인할 기능
- 서비스 이용 동의 후 훈련 시작 여부 확인
- 학습자 이름을 입력하지 않았을 때 오류 메시지 확인
- 학습 시간 선택 및 표시 확인
- 질의응답 체크박스 선택에 따른 질문 수 영역 표시 확인
- 이전 및 다음 버튼을 이용한 단계 이동 확인
- 설정한 내용이 확인 화면에 올바르게 표시되는지 확인
- 완료 버튼을 눌렀을 때 완료 화면으로 이동하는지 확인
- 다시 시작했을 때 입력값과 선택 상태가 초기화되는지 확인

## 새로 추가한 기능
7주차 학습 설정 흐름에 학습 기록 목록을 추가하였다. 학습 완료 후 기록을 저장하고, 각 기록의 완료 상태를 변경할 수 있도록 하였다.

## 인터랙션 시나리오
행동: 학습 설정을 완료하고 기록을 등록한다.
조건: 학습 설정 정보가 입력되어 있는가?
성공 반응: 학습자 이름, 학습 시간, 질문 설정이 기록 목록에 표시된다.
취소: 완료 취소 버튼을 누르면 학습 상태가 '진행 전'으로 변경된다.
다음 행동: 새 학습을 완료하여 기록을 추가하거나 기존 기록의 상태를 변경한다.
